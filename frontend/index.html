What happens to your CV

  • Text extraction, evidence checks, role matching, scoring, editing and export all run locally.
  • Nothing is written to disk. Sessions live in server memory and disappear when the server stops.
  • Only if you add a Gemini key and switch semantic judgement on is the extracted text sent to Google.
